# Agate Beach Golf Course Website

A static HTML website for Agate Beach Golf Course in Newport, OR.

## Viewing the Web Page

### Option 1 — Open Directly in a Browser

Since this is a plain HTML site with no build step, you can open any of the
HTML files directly in your browser:

1. Clone or download this repository.
2. Double-click **`index.html`** (or any other `.html` file) to open it in your
   default browser.

### Option 2 — Local Development Server

A local server avoids potential cross-origin issues and gives you a URL you can
share on your local network.

Using **Python** (built into macOS/Linux; available on Windows):

```bash
# Python 3
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

### Option 3 — GitHub Pages

You can host the site for free with GitHub Pages:

1. Go to your repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under **Source**, select the branch containing your HTML files (e.g. `main`)
   and set the folder to **/ (root)**.
4. Click **Save**.

After a minute or two the site will be available at
`https://<your-username>.github.io/WebsiteTest/`.
